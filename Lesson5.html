02 · Setup
06 / 16
Setting Up Google Analytics

A structured approach to GA4 implementation for accurate, reliable data collection.

01
Create GA4 Property

Set up a GA4 property in Google Analytics Admin. Define data streams (web, iOS, Android). Configure business objectives and industry category.

02
Install the Tracking Code

Add the Google tag (gtag.js) via Google Tag Manager or directly in the <head>. Verify tag firing using GA4 DebugView and Tag Assistant.

03
Configure Events & Conversions

Enable enhanced measurement events. Define key conversions (purchases, form submissions). Set up custom events for unique business goals.

04
Link External Platforms

Connect Google Ads, Search Console, BigQuery, and Merchant Center. Enable cross-platform attribution for full-funnel visibility.

05
Data Governance & Filters

Exclude internal traffic (IP filters). Set up data retention periods. Configure Google Signals for cross-device reporting.

04 · Decision Making
15 / 16
Data-Driven Decision Making

Building a systematic process for translating marketing data into confident, evidence-based actions.

🧪

Experimentation Culture

  • Hypothesis-first testing (A/B, MVT)
  • Minimum detectable effect sizing
  • Statistical significance thresholds (95%)
  • Control vs. variant documentation
  • Fail fast, learn faster mindset
⚖️

Attribution Modelling

  • Last-click (simple, biased)
  • First-click (awareness-focused)
  • Linear (equal credit)
  • Time-decay (recency-weighted)
  • Data-driven (ML-powered, GA4)
🚦

Decision Framework

  • What does the data show?
  • Is the signal statistically significant?
  • What is the business impact?
  • What's the cost of action vs. inaction?
  • Who owns the next step?
